# 📖 Sobre o projeto

O HelpDesk AI é uma plataforma desenvolvida para auxiliar equipes de Service Desk e Suporte Técnico na resolução de incidentes utilizando Inteligência Artificial.

Ao invés de apenas responder perguntas, o sistema conduz o analista por um processo inteligente de investigação, sugerindo perguntas, hipóteses, checklists e possíveis soluções para cada tipo de incidente.

---

# 🚀 Objetivo

Reduzir o tempo de atendimento, padronizar diagnósticos e melhorar a qualidade da documentação técnica.
